# IterWave 运营分析 KPI 口径合同（P2-04）

> 状态：指标定义与数据源约束；当前页面尚未全部实现这些 KPI。  
> 本文禁止用推算值冒充平台真实数据。

## 1. 时间与范围

所有 KPI 必须明确：
- 账号组范围：当前账号组或跨账号组；不得混用。
- 平台范围：单平台或所选平台集合。
- 时间范围：自然日/自然周/自然月或滚动 N 天，统一采用账号组业务时区。
- 统计对象：内容、草稿、发布记录、指标快照或目标。
- 更新时间与样本量。

## 2. 指标定义

| 指标 | 定义 / 公式 | 首选数据源 | 缺失值规则 |
|---|---|---|---|
| 内容生产量 | 统计窗口内创建的内容记录数 | `contents.created_at` | 表/字段不可用显示未知，不显示 0 |
| 草稿产出量 | 窗口内生成的草稿数 | `drafts.created_at` | 与内容生产量分开，避免跨平台变体重复计数 |
| 确认发布量 | 窗口内有用户确认时间的草稿数 | `drafts.user_confirmed_at` | 只代表用户确认，不推断平台回执 |
| 确认发布率 | 已确认发布数 / 可确认发布的已保存草稿数 | `drafts.status`、`user_confirmed_at` | 分母为 0 显示“暂无样本”；不可称为平台发布成功率 |
| 平台发布成功率 | 有平台权威成功回执的发布成功数 / 有明确终态的发布尝试数 | 发布尝试与平台回执记录 | 当前若无完整回执模型，显示“暂不可计算”，不得用确认发布率替代 |
| 互动量 | views、likes、collects、comments、shares 分项总和 | `metrics` 快照 | 每个指标独立保留 NULL；未知不当作 0 |
| 平均互动率 | 按已定义平台口径计算的有效样本均值 | `metrics.interaction_rate` | 展示有效样本量；不能将不同平台原始计数直接合并比较 |
| 粉丝净增长 | 同一账号同一平台最新 followers - 窗口前最近可用基线 | `account_snapshots` | 无同账号基线时显示未知；不能把不同账号快照相加冒充增长 |
| 目标完成率 | 后端目标进度引擎返回的 achievement_rate | `goals` / `/api/goals/summary` | 基线或当前值缺失则 NULL；不得前端自行补零 |

## 3. 必须区分的状态

- 未采集：数据尚未产生。
- 采集失败：有尝试但未得到有效数据。
- 未知/不适用：没有足够来源或分母。
- 真实零值：来源明确返回 0。

所有 KPI 卡片应显示统计窗口、数据更新时间和有效样本量；筛选条件变化时，卡片和明细必须使用同一范围。

## 4. 当前页面差距

当前 Analytics 已有：
- 已采集指标数量、平均互动率和平台内基准。
- 逐篇 views/likes/collects/comments/shares/new_followers 数据。
- 发布后人工回填与历史快照。
- 周复盘建议、TTV、7 日激活率、首次发布率、数据回流完成率等激活指标。

仍未形成统一业务 KPI 总览：
- 内容生产量与草稿产出量未作为清晰、独立的经营指标展示。
- 确认发布量和确认发布率未与平台发布成功率明确分离。
- 多互动指标缺少统一的区间总览与分项聚合。
- 粉丝净增长缺少同账号基线对比摘要。
- 目标完成率尚未纳入同一分析总览。
- 当前页面的“已采集内容”来自指标记录总数，不能当作生产量或发布量。

## 5. 验收要求

- 同一筛选条件下，页面 KPI 与数据库/API 聚合结果逐项一致。
- 内容、草稿、确认发布、平台回执不混为一个数字。
- 所有 NULL/失败/真实零值语义有自动化测试。
- 单平台与跨平台统计均有样例测试，跨平台不可比指标不进行简单求和或平均。
- 统计时区、窗口边界、去重规则有测试。
