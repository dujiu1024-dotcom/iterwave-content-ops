# 账号组北极星与母计划资源基准

## 账号组北极星
- 使用独立于 goals 目标树的账号组级版本档案。
- 每个账号组数据库内最多一个 effective 版本；保存新定位时旧版本归档。
- 版本快照包含定位、经营方向、目标用户、核心价值、长期内容方向、经营模式、平台关系和长期目标。
- 母计划草稿创建时复制当前北极星版本 ID 与快照；历史母计划不随当前北极星变化。

## 母计划资源基准
- 资源基准只引用既有业务档案、原始素材、内部知识来源、外部参考、历史内容与表现、模板/技能和生产线来源，不复制源文件。
- 资源状态区分 confirmed、pending、rejected、missing、unknown。
- 只有明确审核确认的素材计为已确认；业务目录记录只表示已录入，不等同于素材许可确认。
- 母计划审核生效时固化资源基准快照，后续资源变动不改写历史快照。

## 兼容与恢复
- Migration 148 仅新增表、列、索引和触发器，不删除或重写旧目标树、业务资料、素材及计划历史。
- 迁移前按账号组数据库备份策略备份；迁移失败由迁移事务回滚。恢复时使用迁移前备份，避免直接删除已被计划引用的版本表。
- 账号组隔离沿用每个 tenant 独立 SQLite 数据库及 runtime 连接。
